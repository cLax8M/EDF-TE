## Analysis of gene microsynteny by ortholog pair collinearity

We used the frequency of collinear ortholog pairs as a proxy to estimate microsynteny conservation across the 17 clades of the EDF dataset. The analysis followed the approach of Sebé-Pedrós *et al.* (2013), adapted for the broader phylogenetic scope of this study.

### Gene-order extraction

Gene positions were extracted from the GFF/GFF3 annotation files for each of the 241 species in the dataset. For each species we constructed a sorted gene-order list per scaffold from all protein-coding `gene` features, using the `locus_tag` attribute (NCBI-sourced genomes) or the `Name`/`ID` attribute (JGI-sourced genomes) as the gene identifier. Scaffolds carrying fewer than three annotated genes were excluded from the analysis to avoid spurious adjacency calls on uninformative contigs.

### Ortholog identification

Single-copy ortholog pairs for each within-clade species comparison were retrieved from the pairwise ortholog tables generated by OrthoFinder v2 (Emms & Kelly, 2019). Only 1:1 ortholog relationships (one gene per species per orthogroup) were retained; orthogroups with multiple copies in either species were discarded to reduce the effect of recent gene duplications on synteny estimates.

### Collinear pair identification

For each pairwise species comparison (i, j) within the same clade, we identified collinear ortholog pairs as follows. On each scaffold of species i, we extracted the ordered sequence of orthologs shared with species j. For each consecutive pair of orthologs on the same scaffold of species i, we checked whether their corresponding orthologs were also adjacent on the same scaffold of species j, irrespective of gene orientation (to account for local inversions; Putnam *et al.*, 2007). The count of such collinear pairs is denoted *c*ᵢⱼ. The total number of adjacent-ortholog slots considered across all scaffolds in species i (i.e. the sum of (n_orthologs_on_scaffold − 1) over all scaffolds) is denoted *N*ᵢⱼ.

### Null distribution and spurious synteny correction

To account for spurious conservation of gene order arising from random co-localization, we assigned random genomic positions to each gene using the `bedtools shuffle` utility (v2.24; Quinlan & Hall, 2010) in 100 independent rounds per species. Scaffolds were preserved as location constraints (`-chrom` flag). Each replicate used a fixed per-replicate random seed (base seed + replicate index) to ensure reproducibility. For each replicate and each species pair (i, j), the number of spurious collinear pairs was recorded and the mean over 100 replicates (*s*ᵢⱼ) was computed.

### Synteny ratio

The raw synteny score for each species pair (i, j) was computed as:

$$\text{score}_{ij} = \frac{c_{ij} - \bar{s}_{ij}}{N_{ij}}$$

Negative values (i.e., pairs with fewer collinear orthologs than expected by chance) were set to zero. Scores were then normalized to the [0, 1] interval within each clade using the maximum observed score in that clade as the reference:

$$r_{ij} = \frac{\text{score}_{ij}}{\max_{kl}(\text{score}_{kl})}$$

Normalization was performed independently for each clade, because the absolute synteny scores are not comparable across clades with very different phylogenetic divergence scales and genome architectures. The species pair with the highest raw score within each clade is reported as the normalization reference.

### Visualization

For each of the 17 clades, a heatmap of pairwise *r*ᵢⱼ values was produced using the seaborn clustermap function (v≥0.13; Waskom, 2021) with average linkage clustering and Euclidean distance on the *r*ᵢⱼ vectors. Species were therefore ordered by overall synteny similarity. Heatmaps were rendered as PDF (font type 42) and PNG (300 dpi) using matplotlib (v≥3.8; Hunter, 2007).

For selected species pairs with high synteny ratios, syntenic gene-pair links were visualized on genome scaffolds using Circos v0.67 (Krzywinski *et al.*, 2009). Only the top 30 scaffolds by collinear-pair count per species were included in Circos plots to maintain readability.

### Assembly quality note

Species with highly fragmented genome assemblies (scaffold N50 < X Mb; threshold to be determined from the assembly metadata in `Samples.xlsx`) may show artificially low synteny ratios because short scaffolds reduce the power to detect adjacent ortholog pairs. Such species are flagged in the heatmap figures with an asterisk (*).
